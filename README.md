# 📂 Projetos de Lógica & Algoritmos

## 🎯 Objetivo
Este repositório reúne uma coleção de scripts desenvolvidos para aprimorar minha lógica de programação e consolidar conhecimentos na sintaxe do JavaScript. Aqui exploro resolução de problemas, e algoritmos fundamentais.

## 🚀 Tecnologias Utilizadas
* **JavaScript** (ES6+)
* **Node.js** (Ambiente de execução)

## ⚡ Como executar

Para rodar os projetos na sua máquina, você precisará ter o [Node.js](https://nodejs.org/) instalado.

1. Clone o repositório ou baixe os arquivos.
2. Abra o terminal na pasta do projeto.
3. Execute o comando abaixo (substituindo pelo nome do arquivo desejado):

```bash
node nome-do-arquivo.js
